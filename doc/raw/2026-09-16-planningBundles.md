# Brief – bundles in IziWeddy planning

English translation of the project owner's request of 2026-09-16.

---

In the "Plánování" (Planning) section we should also add the option that one
thing covers several items.

To give an example: one venue offered us Místo obřadu (ceremony venue), Místo
veselky (reception venue), Jídlo (food), Pití (drinks), Květiny (flowers),
Výzdoba (decorations) and hudba (music) for a single price.

It would need some kind of a group, into which I can enter everything that the
group includes.

---

## Decisions taken with the owner on the same day

Asked because the brief allows two readings.

1. **How the group works.** A bundle has a name, a link, one price and a status;
   items are added inside it and each item keeps its own section. An item in a
   bundle has no price of its own – it shows "v balíčku" (in the bundle)
   instead. An item that already exists can be moved into a bundle.
   *(The alternative – a bundle as a set of ticked sections with nothing written
   inside – was rejected: it cannot record that the music is a four-hour band.)*
2. **Music.** The example mentions music, which had no section. A twelfth
   section `music` (Hudba) was added between Výzdoba (decorations) and Oblek
   (suit); the dashboard now counts "decided X of 12".
