# Brief – MapTap leaderboard

English translation of the project owner's request of 2026-10-09.

---

Make a new app. It will be a MapTap leaderboard.

It is purely for internal use, so it should have no link on the portal. It
will live at the address `/maptap`.

It will be for signed-in users only. They will be able to enter a score. That
comes as a string like this:

```
www.maptap.gg October 9
94:sports_medal: 91:crown: 80:clap: 88:tada: 17:dizzy_face:
Final score: 660
```

The `:sports_medal:` parts are emoji, which we can show as well, but we can
also sanitise them – that is up to you.
