# Brief – IziWeddy plan settings and roles

English translation of the project owner's request of 2026-09-16.

---

I would add a section with the settings of a wedding plan.

It should contain:
- Access to the plan – the Admin is the one who created the plan.
- Manager – can add, remove, basically anything, but does not see the settings.
- Viewer – sees the plan but cannot do anything, everything read only in effect.

Also, in the settings it will be possible to edit all the things that are now in the Couple part – the name of the wedding, the date.

I would also put there the option to delete this particular plan.

---

## Answers to follow-up questions (2026-09-16)

**Inviting people:** by e-mail, with a pending invitation. The admin enters an
e-mail and a role. Whoever has an account gets access right away and an
informational e-mail; whoever does not gets an invitation, and the access
appears once they register. Storing the invited person's e-mail is covered by
the privacy policy and the invitation deletes itself after a while.

**Where the settings live:** the fifth tab in the bottom navigation, visible to
the admin only.

**Wedding title and date:** moved to the settings – the Couple screen keeps only
the groom and the bride.
